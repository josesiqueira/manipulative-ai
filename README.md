# manipulative-ai: VAKKI 2026 release

The code that ran the chatbot experiment presented at VAKKI 2026 (April 2026),
from Tampere University. Participants chatted with a bot secretly aligned with
one of four abstract political blocs: `conservative`, `red-green`, `moderate`
and `dissatisfied`. The application is in [`societal-discussion/`](societal-discussion/).

The application code is exactly as it ran in the experiment (commit `a0e8c79`;
working and planning documents were later removed from the published history).
This release only adds this README and the four prompt files below.

## How the bots were steered in the experiment

- **Model**: OpenAI GPT-4o, temperature 0.1, at most 1024 output tokens.
  `societal-discussion/README.md` says "Claude API (Anthropic)"; that is wrong
  for the experiment. The code supports both providers, and OpenAI was used.
- **System prompt only**: each bloc had its own system prompt describing its
  values and rhetorical style, in English and in Finnish.
- **No few-shot examples**: the code was written to add three random statements
  from the curated 261-statement dataset (`persuasion_dataset_Unified_EN-3_CLEANED.xlsx`)
  to the prompt. In the deployed database the `political_statements` table was
  empty (the dataset was never imported), so the code skipped the examples
  section without any error. The bots ran on the system prompts alone.
- **Topic not in the prompt**: the participant's chosen topic was passed to the
  prompt builder but not written into the prompt; the bot learned the topic
  only from what the participant wrote.
- The bloc prompts were not edited in the admin panel during the experiment.
