# Tampere University official logo files

Downloaded from Markkinointipankki (HAKA login required):
https://markkinointipankki.tuni.fi/ → Materials → Logos → Logos for digital environments

## Required files (exact names)

| Filename | Which download | Used by |
|---|---|---|
| `tau-en-negative.svg` | English, one-line, **negative (white)**, SVG | Institutional bar + footer bar (purple ground), `/en` |
| `tau-fi-negative.svg` | Finnish (`Tampereen yliopisto`), one-line, **negative**, SVG | Same, `/fi` |
| `tau-en-purple.svg`   | English, one-line, **purple**, SVG | Any light background |
| `tau-fi-purple.png`   | Finnish, one-line, **purple**, PNG | Any light background. The only raster file; fine at small sizes, replace with the SVG for large-format use |

The one-line version is chosen deliberately: TAU's guidance recommends it
"in low spaces, such as website top bars", which is exactly what we have.

## Brand rules we must not break

From the official guidance:

- The symbol and text **may not be separated**. Never render the symbol alone.
- Do not stretch, thin, bolden or otherwise process the logo, and do not change
  the proportions between symbol and text.
- Leave clear space around the logo with no other text in it. Our bar keeps the
  project name in a separate cell behind a divider for this reason.
- **Do not combine faculty or unit names with the logo.** "EVIL-AI Research
  Project" is deliberately a separate element, not part of the lockup.
- Ensure sufficient contrast with the background: the negative logo on our
  `--tau` purple, never the purple logo on it.
- Do not recolour. Only the official purple or the official white.

Until these files are added the component renders a plain text wordmark, which
is honest, rather than an unofficial redrawing of the symbol.
